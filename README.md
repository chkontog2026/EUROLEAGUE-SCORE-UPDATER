# EuroLeague Courtside

Ξεχωριστό web app για πρόγραμμα, live σκορ, αποτελέσματα, επίσημη βαθμολογία και αγαπημένες ομάδες EuroLeague. Ελληνικό περιβάλλον, responsive εμφάνιση και ώρες Ελλάδας. Χωρίς εξωτερικές runtime εξαρτήσεις.

## Εκκίνηση

Απαιτεί Node.js **22+** για απευθείας σύνδεση (`npm run start:vps`) ή **24.5+** για τον cloud proxy (`npm start`). Δεν χρειάζεται `npm install`.

```bash
cd /workspace/EUROLEAGUE-SCORE-UPDATER
npm start
```

Προεπιλεγμένη θύρα: `3091`. Το `npm start` χρησιμοποιεί τις μεταβλητές proxy του περιβάλλοντος μέσω `--use-env-proxy`, με ενεργή επαλήθευση TLS. Το `npm run dev` επανεκκινεί τον server όταν αλλάζει κώδικας.

Για ανάπτυξη χωρίς πρόσβαση στο feed:

```bash
npm run demo
```

**Το demo έχει εικονικούς αγώνες και αποτελέσματα.** Εμφανίζει μόνιμη ένδειξη και δεν ενεργοποιείται αυτόματα σε αποτυχία του πραγματικού API.

## Λειτουργία

- Πρόγραμμα, live αγώνες και αποτελέσματα, με αναζήτηση ομάδας και φίλτρο αγωνιστικής.
- Βαθμολογία από το επίσημο feed, χωρίς ανακατασκευή ή επινόηση κατάταξης σε ισοβαθμίες.
- Αγαπημένες ομάδες αποθηκευμένες τοπικά στον browser.
- Ανανέωση server και browser κάθε 20 δευτερόλεπτα. Το κουμπί Ανανέωση διαβάζει την πιο πρόσφατη κατάσταση του server.
- Σε αποτυχία διατηρούνται στη μνήμη τα τελευταία διαθέσιμα δεδομένα με ορατή προειδοποίηση. Με επανεκκίνηση χρειάζεται νέα επιτυχής ανάκτηση.
- Αμφίσημες ημερομηνίες χωρίς timezone δεν μετατρέπονται αυθαίρετα σε ώρα Ελλάδας.
- Οι αρχικοί μηδενικοί πόντοι προγραμματισμένου αγώνα εμφανίζονται ως `—`, όχι ως πραγματικό σκορ.

Ρυθμίσεις μέσω exported environment variables:

| Μεταβλητή | Προεπιλογή | Περιγραφή |
| --- | --- | --- |
| `PORT` | `3091` | Θύρα HTTP |
| `EUROLEAGUE_SEASON` | Αυτόματη | Έτος έναρξης, π.χ. `E2026` για 2026/27, αλλαγή τον Ιούλιο |
| `DEMO_MODE` | `false` | `true` για ρητή ενεργοποίηση demo |

Η εμφάνιση ώρας χρησιμοποιεί πάντα `Europe/Athens`. Το `.env.example` είναι παράδειγμα· η εφαρμογή δεν φορτώνει αυτόματα `.env`.

## Πηγή δεδομένων και περιορισμοί

HTTPS προς `api-live.euroleague.net`:

- `/v2/competitions/E/seasons/{season}/games?limit=100&offset=0`
- `/v3/competitions/E/seasons/{season}/rounds/{round}/basicstandings`

Οι διαδρομές βασίζονται στην υλοποίηση του [euroleague_api](https://github.com/giasemidis/euroleague_api). Δεν προστέθηκε εξάρτηση από αυτό το πακέτο. Η βαθμολογία ζητείται για την πιο πρόσφατη αγωνιστική της κανονικής περιόδου που έχει ξεκινήσει. Το feed μπορεί να εμφανίζει διαφορετικό status ή σχήμα ανά σεζόν: άγνωστα στοιχεία απορρίπτονται ή παραμένουν άγνωστα, δεν αντικαθίστανται με demo.

**Η πραγματική σύνδεση δεν έχει επαληθευτεί στο τρέχον cloud περιβάλλον:** ο egress proxy μπλοκάρει τον προορισμό. Μετά την ενεργοποίηση του domain χρειάζεται έλεγχος της πραγματικής απάντησης, ειδικά ονομάτων πεδίων βαθμολογίας, pagination, timestamps και live status. Τα tests ελέγχουν αντιπροσωπευτικές απαντήσεις μέσω mock, όχι πραγματικό feed. Δεν υποσχόμαστε live ενημέρωση μέχρι αυτός ο έλεγχος να ολοκληρωθεί.

Δεν περιλαμβάνονται ακόμη box scores παικτών, injury reports, αποδόσεις, browser notifications ή Android app.

## Έλεγχοι

```bash
npm test
curl --fail http://127.0.0.1:3091/health
curl http://127.0.0.1:3091/api/dashboard
```

Το `/health` επιστρέφει `503` αν δεν υπάρχουν επιτυχώς ανακτημένα δεδομένα ή είναι παλιά/η τελευταία ανάκτηση απέτυχε. Επιστρέφει χωριστά `standingsError` για αποτυχία βαθμολογίας. Ένα `ok: true` με `demo: true` επιβεβαιώνει μόνο τη δοκιμαστική λειτουργία.
